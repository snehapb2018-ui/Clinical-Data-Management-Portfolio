## eCRF Specifications, Annotated CRF & Test Script Project

A self-initiated project demonstrating the end-to-end eCRF design and validation workflow that follows protocol approval in a clinical trial — from drafting CRF specifications through to UAT test scripting.

**Forms covered:** Demography, Routine Haematology, Routine Clinical Chemistry

**What's included:**
- **CRF Specifications & Annotations** — detailed field-level specifications (data formats, entry guidelines) and annotated CRFs mapping fields to standard data models (e.g. CDISC SDTM), to guide database programmers
- **Edit Check Specifications** — logical validation rules and query messaging to ensure data integrity (range checks, format checks, cross-field logic)
- **UAT Test Scripts** — predefined test steps, inputs, and expected outcomes to validate that programmed edit checks fire correctly prior to study go-live
